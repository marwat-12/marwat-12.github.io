# Mudassir Ghazi | Portfolio Website

Personal portfolio of **Mudassir Ghazi (marwat-12)**, a BS Software Engineering student and backend developer from Islamabad, Pakistan.

**Live site:** https://marwat-12.github.io

## About

I build backend systems, mobile apps and office networks using Java, Python, SQL, Dart and Cisco Packet Tracer. This site shows my projects and skills in one place.

## Features

- Animated network background with moving data packets that react to the mouse
- Typewriter text that cycles through my roles
- Project cards linked to my GitHub repositories
- Dark and light mode, responsive on mobile and desktop
- SEO ready: page title, meta description and structured data for search engines

## Projects shown

- **FoodExpress-App**: Flutter food delivery app (Dart)
- **BBMS-DBMS-Project**: database management project (Java)
- **Cisco-Packet-Tracer-Network**: multi-router, switch and LAN/WAN topology
- **Building-a-Multi-Office-Network-Cisco**: three-office network with Security Area and Server Room
- **Online-Banking-System-SQE**: manual and Selenium testing, security testing (Python)
- **shadowlens-xdr**: forensic file-analysis and threat-triage CLI tool (Python)
